# Executive Presence

Create a premium executive-style personal portfolio website for me.

The website should feel sophisticated, professional, modern, high-end and trustworthy. Avoid the typical colorful developer portfolio aesthetic. The design should look like a personal website for an executive, entrepreneur, consultant, business professional or senior technology leader.

DESIGN STYLE:

- Premium executive aesthetic

- Minimal and sophisticated

- Strong visual hierarchy

- Lots of whitespace

- Elegant typography

- Subtle animations

- Professional rather than playful

- Fully responsive on desktop, tablet and mobile

- Smooth scrolling

- Modern glass/subtle card effects where appropriate

- Avoid excessive gradients and excessive animations

COLOR PALETTE:

- Main background: #0B1220 (deep navy)

- Secondary background/card: #111827

- Primary blue: #2563EB

- Accent gold: #D4AF37

- Main text: #F8FAFC

- Secondary text: #94A3B8

- Borders: rgba(255,255,255,0.08)

Use gold very sparingly as a premium accent.

TYPOGRAPHY:

Use a premium modern sans-serif font such as Inter or Manrope.

Headings should be bold and elegant.

Body text should be highly readable.

NAVIGATION:

Create a sticky transparent/dark navigation bar.

Logo:

Use my name as the logo.

Navigation items:

- Home

- About

- Expertise

- Experience

- Projects

- Contact

Add a highlighted "Let's Talk" button on the right.

HERO SECTION:

Create a visually impressive executive hero section.

Left side:

- Small eyebrow text: "WELCOME TO MY PORTFOLIO"

- Large heading:

  "[YOUR NAME]"

- Professional title:

  "[YOUR PROFESSIONAL TITLE]"

- Short statement:

  "I build meaningful solutions, create measurable impact, and turn ambitious ideas into reality."

Add two buttons:

- View My Work

- Let's Connect

Right side:

Create an elegant professional profile image area with a premium circular/rounded portrait treatment.

Add subtle decorative elements using the blue and gold accent colors.

ABOUT SECTION:

Create an executive-style About Me section.

Include:

- Professional introduction

- Career background

- Personal philosophy

- A "More About Me" button

Add a small statistics area:

- Years of Experience

- Projects Completed

- Clients / Organizations

- Certifications / Achievements

EXPERTISE SECTION:

Title:

"Expertise"

Subtitle:

"Areas where I create the most value."

Create 4-6 elegant cards.

Example categories:

- Leadership

- Strategy

- Technology

- Business Development

- Project Management

- Innovation

Each card should have:

- Minimal line icon

- Title

- Short description

- Subtle hover animation

EXPERIENCE SECTION:

Create a premium vertical timeline.

For every experience:

- Job title

- Company

- Location

- Start date - End date

- 2-4 achievement bullets

Use gold/blue indicators on the timeline.

PROJECTS SECTION:

Title:

"Selected Work"

Create large premium project cards.

Each project should contain:

- Project image

- Project name

- Short description

- My role

- Technologies/tools

- Key result

- View Project button

Use a clean 2-column desktop layout and 1-column mobile layout.

ACHIEVEMENTS SECTION:

Create a dark premium section with large statistics.

Example:

"10+ Years Experience"

"50+ Projects"

"25+ Clients"

"15+ Certifications"

Make the numbers visually prominent.

TESTIMONIALS SECTION:

Create 3 elegant testimonial cards.

Each card:

- Quote

- Person name

- Job title

- Company

CONTACT SECTION:

Create a premium contact section.

Heading:

"Let's Work Together"

Text:

"Have an idea, project, or opportunity in mind? I'd love to hear from you."

Include:

- Name

- Email

- Subject

- Message

- Send Message button

Also display:

- Email

- LinkedIn

- GitHub

- Location

FOOTER:

Create a minimal dark footer.

Include:

- My name

- Short tagline

- Navigation links

- Social links

- Copyright

ANIMATIONS:

Use subtle premium animations:

- Fade-in on scroll

- Smooth section transitions

- Slight card lift on hover

- Button hover animations

- Image reveal animation

Do NOT use distracting animations.

RESPONSIVENESS:

The website must look excellent on:

- Desktop

- Laptop

- Tablet

- Mobile

On mobile:

- Convert navigation into a hamburger menu

- Stack hero content

- Stack project cards

- Stack statistics

- Maintain comfortable spacing and typography

TECHNICAL REQUIREMENTS:

- Use React

- Use Tailwind CSS

- Use reusable components

- Keep the code clean and maintainable

- Use semantic HTML

- Optimize for SEO

- Add proper page title and meta description

- Add accessible labels to forms and buttons

- Optimize images

- Ensure strong contrast and accessibility

IMPORTANT:

Do not use placeholder lorem ipsum text.

Where my personal information is not yet provided, use clearly marked placeholders such as:

[YOUR NAME]

[YOUR PROFESSIONAL TITLE]

[YOUR BIO]

[YOUR EMAIL]

[YOUR LINKEDIN]

[YOUR LOCATION]

Make the final website feel like a premium executive personal brand website, similar in quality to a high-end consulting, leadership or technology executive website.
